# Sample images

Shared test images for the whole team. Keep each file under ~2 MB.

Add a few of each:
- **Dark** and **bright** images (histogram, equalization)
- **Low-contrast** image — values squeezed in a narrow range (normalization, equalization)
- **Colorful** image (R/G/B histograms, per-channel color shift)
- **Grayscale** image (check every page works in gray mode)
- Image with **clear edges** (buildings, text, shapes) (edge detection)
- **Two portraits / faces of similar size and pose** (hybrid images — e.g. a person and an animal)
